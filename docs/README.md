# RabbitMQ Genesis Kit Documentation

This directory contains comprehensive documentation for the RabbitMQ Genesis Kit, organized by topic. These documents provide detailed guidance beyond what is covered in the main README.md and MANUAL.md files.

## Contents

- **architecture/** - Detailed technical architecture and components
- **deployment/** - Deployment guides for different scenarios
- **features/** - In-depth documentation for each feature
- **operations/** - Operational procedures and maintenance
- **integration/** - Integration with other systems
- **troubleshooting/** - Detailed troubleshooting guides
- **examples/** - Example deployments and configurations

## Using This Documentation

Each documentation section contains markdown files that can be viewed directly on GitHub or using any markdown viewer. The documentation is designed to complement the main README.md and MANUAL.md files, providing more detailed information on specific topics.

For getting started, please refer to the [README.md](../README.md) in the root directory.
For comprehensive information on parameters and features, see [MANUAL.md](../MANUAL.md).
